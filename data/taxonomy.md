## Research Taxonomy

- **Code Generation**
  - **Domain-Specific Code Generation**: Focuses on using LLMs for code generation in specialized domains (e.g., power systems, industrial automation) with techniques like reinforcement learning and prompt engineering.
  - **Evolutionary Code Optimization**: Uses evolutionary algorithms guided by LLMs to iteratively improve code, prompts, or heuristics through self-referential mechanisms.
- **Language Model Training & Decoding**
  - **Diffusion Language Model Decoding**: Improves decoding in diffusion language models for text generation via parallel strategies, token selection, and architectural enhancements.
  - **On-Policy Distillation**: Enhances knowledge distillation from teacher to student LLMs by addressing distribution mismatch and leveraging student-generated trajectories.

## Rationale

The top-level split separates research focused on generating and optimizing code (applied) from research on improving the underlying language model training and decoding processes (methodological). This distinction reflects the two main thrusts: using LLMs for code generation tasks versus advancing the models themselves. The sub-categories further differentiate specific approaches within each area.
